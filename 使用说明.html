1. 快速开始

  1. 第 1 步 把整个文件夹从 U 盘拷贝到 Windows 电脑本地磁盘(如 D 盘或桌面)。
  2. 第 2 步 双击 零件产品分析.exe。
  3. 第 3 步 如果 Windows 弹出蓝色的「Windows 已保护你的电脑」(SmartScreen):点「更多信息」→「仍要运行」。这是所有未购买签名证书的小工具都会遇到的提示,程序本身不联网。
  4. 第 4 步 会出现一个黑色小窗口(本地服务器)+ 浏览器自动打开 http://localhost:4173。使用期间别关黑窗口;用完直接关掉它即可停止,数据不会丢。
💡 双击 exe 没反应或浏览器没自动开?手动在浏览器地址栏输入 http://localhost:4173。还不行就用备用方式:双击文件夹里的 备用启动(无需exe).bat。

2. 数据存在哪里 · 备份

  • 所有数据保存在浏览器的本地存储(localStorage)里,跟着「这台电脑 + 这个浏览器」走。U 盘里拷的是程序,不是数据。
  • 因此:换电脑、换浏览器(如从 Edge 换到 Chrome)、或清除浏览器数据,都会看不到原来的数据——请养成备份习惯。
  • 备份方法:「导入/导出」页 →「整体备份」下载一个 JSON 文件;在新电脑上把这个 JSON 拖进导入区即可原样恢复(含所有设置)。
  • 请一直用同一个浏览器打开,并保持地址是 localhost:4173(exe 和备用 bat 用的是同一个端口,数据互通)。

3. 九个页面逐一介绍

① 产品

登记产品名(如 Alpha、Beta)。产品名会成为工人能力表的列、订单引用的类型。

② 零件(VC)

  • 每行一个 VC(3 位代码):难度(高/低/无,决定谁能做)+ 重复设计工时 t7 + 首单设计工时 t8。
  • 页面上方有「校对系数」设置:校对工时 = 设计工时 × 系数(默认 0.3,推荐在「工时台账」页用实际数据一键校准)。
  • 支持导入 parts.xlsx(第1列=VC,第8列=t7,第9列=t8)。

③ 工人能力

  • 每人每产品两格:设计等级和校验等级(A/B/C,留空=不做)。A=能做高/低/无,B=低/无,C=仅无。等级只决定能不能做,工时由 VC 表决定。
  • 页面下方有「请假登记」:选人、填起止日期、每日请假小时数(留空=整天)。只影响排期的产能,不影响分析/复盘。

④ 订单

  • 每行一张订单:订单号 + 产品 + VC 列表 + 设计/校对工人 + 交付日期 + 创建日期 + 实际完成日期。
  • 智能导入:点「导入 orders.xlsx」,直接丢公司系统导出的大表——程序会自动在整张表里找表头行,按关键词(Sales Order / Sales Order Item / Engineer VC / Designer / Checker / Product Series / BOM Required Date / Create On / Actual BOM Finish Date 等,中英文都认)匹配各列,弹出映射确认框让你核对后导入。
  • 订单号 = Sales Order + "-" + Item(自动去前导 0),如 123456789-1200;全站的表和导出都用它标识订单。
  • 实际完成日期是分水岭:填了 = 已完成 → 进「复盘」;没填 = 未完成 → 进「排期」。

⑤ 导入/导出

拖放区自动识别 parts / workers / orders / HourReport 等文件;可导出与 analyze.py 兼容的 Excel;整体备份/恢复也在这里。

⑥ 分析 — 理论工时 vs 实际报工

  • 理论工时汇总:全部订单按 VC 表算出的设计/校对理论工时、团队日产能、全队需要多少个工作日做完。
  • 理论 vs 实际报工(全员合计):导入工时台账后,逐环节对比 理论 / 实际 / 差值 / 比值。
  • 每位工人 理论 vs 实际:每人被指派订单的理论工时 vs 台账实际报工。
  • 订单工时明细表:每张订单的 VC 数、系数、设计/校对工时来源一目了然。

⑦ 排期 — 只排未完成的订单,从今天开始

  • 三种排法,逐单给出预计开始/完成日期和提前/迟交天数(设计/校对工人也标在每行):
    • ① 连续排:不管交期,按创建日期排队,干完一个做下一个;
    • ② 按交期(slot):交期最早的先做,提前做完自动把后面的任务填进空余时间;
    • ③ 贴近交期(参考):尽量晚开工,在交付日前 N 个工作日刚好完成(缓冲可调)。
  • 产能口径:人数 × 每人每日工时,再扣年假均摊(可设)和「请假登记」的精确请假;工作日只算周一至周五。
  • ④ 每位工人 · 个人排期:每个人自己的时间线——设计工时进设计工人、校对在该单设计完成后进校对工人;上方下拉框可切换三种口径(①连续排 / ②按交期 / ③贴近交期倒排);汇总表列出每人的单数、总工时、最早开工、预计忙到;选一个工人可看逐日进度条和当天经手的订单。
  • ⑤ 重新分配建议:自动建议把超载工人的活转给较闲的人——有能力评级的按评级(评级不胜任的绝不推荐),没有能胜任的评级人选时按「谁空谁来」并标「能力未填」;设计环节只转给设计、校对只转给校对;很多张小单会自动打包成一整块转给同一个人。只是建议,不会改动任何数据。
  • 长表格支持折叠:超过 30 行的小节默认收起(排期/复盘两页都是),点小节标题展开/收起,顶部有「全部展开 / 全部折叠」按钮;折叠不影响导出。
  • 自动提醒:交期已过的逾期单、疑似填错的超远交期(如 2027)。
  • 「导出报告」包含完整每日时间线、两张完整逐单表、每人每日负荷(按页面当前选中的口径)和重新分配建议完整清单(不受页面显示行数限制)。

⑧ 复盘 — 只看已完成的订单(最早创建日 → 今天)

  • 实际交付表现:准时率、迟交单数、中位/最长迟交(都按每张单自己的交付日期算)。
  • 完成速度:一半订单 ≤X 个工作日、九成 ≤Y 天、最慢 5%,加区间分布条。
  • 每位工人负载:实际报工 ÷ 一年可用工时((260 − 年假) × 每人每日工时);超 100% 标红。
  • 标准工时 vs 实际报工:每人的效率 = 标准 ÷ 实际(>100% 比标准快)。

⑨ 工时台账 — 对接 hour report

  • 导入 hour report 导出的 HourReport_{年}_Analysis.xlsx(拖进导入页或点台账页按钮,按工作表 Data (long) 自动识别)。
  • 看每人全年报工:订单设计/校对、加班、请假、利用率、订单工时/日。
  • 📐 实际工时口径(重要):一键把三个参数换成实际值——每人每日工时(平均每天真正花在订单上的小时数)、校对系数(实际校对÷设计比例)、排期年假归零(实际数据已含请假)。应用后分析/排期/复盘全部按真实节奏计算,强烈建议导入台账后点一次。

4. 核心计算规则速查

规则内容
设计工时Σ(订单内各 VC 工时) × 数量系数:≤5 个 VC ×1,6–10 ×1.2,>10 ×1.5
首单/重复同一「产品+VC」按创建日期最早的一单用 t8(首单),之后用 t7
特殊值工时为 0 → 按 0.03h;VC 999 → 固定 0.08h
校对工时设计 × 校对系数(默认 0.3,可用台账实际值校准)
作废订单设计/校对工人为 null / special order / order canceled 的订单整张不参与
工作日只算周一至周五;年假按每年 260 个工作日均摊扣产能
订单号Sales Order + "-" + Item(去前导 0),如 123456789-1200
已完成/未完成看「实际完成日期」是否填写:未完成→排期,已完成→复盘

5. 推荐工作流

  1. 首次使用:导入订单大表(订单页智能导入)→ 导入零件 parts.xlsx → 导入 HourReport 台账 → 台账页点「应用实际口径」 → 依次看「分析 / 排期 / 复盘」。
  2. 日常/每月:重新导入最新的订单表和台账(覆盖导入)→ 重跑三个页面即可。
  3. 随手:每次大改动后到「导入/导出」页做一次整体备份。

6. 蓝/橙对账标色是什么

工人名册(工人能力页)和工时台账按名字精确匹配。写法不一致(如名册叫 Sam、台账叫中文名)就对不上,程序会用颜色标出来:

  • 🔵 蓝底 名册里有、台账里没有这个名字 —— 要么真没报工,要么两边名字写法不同;
  • 🟠 橙底 台账里报了工、名册里没有这个名字。

出现成片蓝/橙时,把其中一边的名字改成一致写法即可自动对上(工时台账页顶部的两条彩色提示会列出具体名单)。

7. 常见问题 FAQ

问题答案
双击 exe 被 Windows 拦截SmartScreen 对没有付费签名的小工具都会提示。点「更多信息」→「仍要运行」。程序不联网,可先断网验证。
关掉黑窗口数据会丢吗不会。数据在浏览器里,黑窗口只是本地服务器。下次双击 exe 接着用。
浏览器没自动打开手动访问 http://localhost:4173;或用 备用启动(无需exe).bat。
数据突然"不见了"八成是换了浏览器、换了地址(如 127.0.0.1 vs localhost)或清了浏览器数据。回到原浏览器 + localhost:4173;找不回就用之前的整体备份 JSON 恢复。
排期出现很久以前/很远的年份时间线终点 = 最晚交付日期。程序会自动点名"交付日期比最晚创建日晚超过 1 年"的疑似笔误订单,在订单页搜索该年份修正即可。
复盘里有人是 0 小时(蓝底)不是没干活,是名字对账问题或没报工,见上一节。
会不会上传我们的数据不会。exe 只监听本机(127.0.0.1),网页所有计算在浏览器内完成,Excel 解析用内置库。可以在断网状态下完整使用。
能多人同时用吗它是单机工具。要共享结果,用各页的「导出报告 .xlsx」发 Excel。
